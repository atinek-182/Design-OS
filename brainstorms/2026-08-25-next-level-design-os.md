# Next-Level Antigravity Design OS: Master Architecture & Discovery Specification
Date: 2026-08-25 · Goal: Elevate the 126+ skill catalog into an integrated, zero-friction, end-to-end Autonomous Design Engineering Operating System (References, Docs, Assets, Deterministic Scripts, Sequential Non-Conflicting Pipelines, and Interactive Live Harnesses).

## Summary / Key Decisions
- **Core Orchestration Model**: 10-Stage Sequenced Design Engineering Pipeline.
  - **Stages 1–5 (Pure Planning & Reference Ingestion - Zero Code)**:
    - **Stage 1 (Brand, Mood & Tech Stack Selection)**: 2–4 deep Socratic questions presenting 3 distinct visual archetypes per question + explicit tech stack selection (React/Next.js/Vite/Astro/HTML5/Vanilla CSS/Java/Svelte/Vue/etc.) -> saves `context/1-brand-and-vision.md` and sets stack target in `context/5-code-standards.md`.
    - **Stage 2 (References & Deconstruction)**: 
      - Multi-modal ingestion of URLs, screenshots, code snippets, and video motion references (via `video-to-superprompt`, `html-to-interaction-prompts`, `explain-interface`).
      - Fallback to Centralized Archetype Vault if user has no custom links.
      - Socratic Keep vs Discard breakdown and OKLCH token re-binding -> saves `reference/MANIFEST.md`.
      - Global Reference Library maintained at the Design OS root (`references/vault/`) so reference intelligence is reusable and upgradeable across all future projects.
    - **Stage 3 (Tokens & Contrast Math)**: Mathematical calculation of OKLCH palettes, WCAG 2.2 AA contrast matrix, fluid typography/spacing -> saves `context/2-design-tokens.json`.
    - **Stage 4 (Macrostructure & IA)**: Section rhythm, anti-monoculture hero selection, layout rotation -> saves `context/3-ui-manifest.md`.
    - **Stage 5 (Motion & Interaction)**: GSAP/Lenis scroll physics, bezier curves, micro-interactions -> saves `context/4-motion-choreography.md`.
  - **Stages 6–10 (Implementation Wave & Quality Assurance)**:
    - **Stage 6**: Layout Skeleton & Responsive Grid Scaffolding.
    - **Stage 7**: Component Crafting & Visual Surface Layering.
    - **Stage 8**: Deterministic Asset Binding (CC0 Openverse photography, Iconify Solar Duotone vectors, WebGL GLSL shaders).
    - **Stage 9**: Playwright 5-Viewport Visual Quality Gate (`verify`) with **Autonomous Self-Healing Loop** (auto-fixing horizontal overflows, contrast slips, and broken assets) + **Operator Visual Checkpoint** with clickable screenshot artifacts.
    - **Stage 10**: Multi-Engine AST Anti-Slop Audit, Code Standards Check (`context/5-code-standards.md`), and Final Deliverable Handoff.

- **Operator Interaction & Execution Model**:
  - **Dual Chat-CLI Synergy (Option A + B)**: The user operates exclusively in natural language / chat slash commands (`/design-os`, `/design-os resume`, answering Socratic questions). The AI agent autonomously manages all underlying CLI scripts, Python math engines (`scripts/design_os.py`), AST linters, and Playwright viewports behind the scenes.

- **State Management & Multi-Session Persistence**:
  - Adapted 7-File Design Context Foundation (`context/1-brand-and-vision.md` through `context/7-seo-and-a11y.md`).
  - Multi-session zero-loss recovery via `context/6-progress-tracker.md` and `docs/wayfinder/design-map.md`.

- **Quality & Verification Strategy (Option A + B + C Tri-Engine)**:
  - Self-healing auto-fix engine for deterministic layout/contrast/lint bugs.
  - Multi-viewport screenshots generated across 5 screen profiles (1920px, 1440px, 768px, 375px, 667px).
  - Explicit operator checkpoint review and feedback loop before final sign-off.
