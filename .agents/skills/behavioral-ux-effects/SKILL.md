# Behavioral UX Effects & Memory Architecture

## 1. Peak-End Rule
People judge an experience based on how they felt at its peak (most intense point) and at its end.
- Design rewarding completion states, celebration micro-animations, and frictionless checkout conclusions.

## 2. Zeigarnik Effect
Incomplete tasks create cognitive tension that motivates return.
- Implement percentage progress bars ("Profile 80% complete"), saved draft indicators, and clear next steps.

## 3. Serial Position Effect
Users best recall the first (Primacy) and last (Recency) items in a sequence.
- Place the most critical navigation links or pricing tiers at the first and last positions.

## 4. Von Restorff (Isolation) Effect
When multiple similar objects are present, the one that differs from the rest is most likely to be remembered.
- Ensure the primary conversion button or recommended pricing tier uses a distinct high-contrast accent token.
