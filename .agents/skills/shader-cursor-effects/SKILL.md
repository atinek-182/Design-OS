# WebGL & WebGPU Interactive Cursor Shaders

Provides fluid distortion, water ripples, and halftone particle trails attached to mouse movement.

## Features
- **Fluid Cursor Ripples**: Water ripple distortion over canvas textures and media images.
- **ChromaFlow Halftone Trail**: Twinkling particles masked through a DotGrid.
- **Performance Guard**: Automatic fallback to standard pointer events on touch/mobile devices or low-power GPUs.
