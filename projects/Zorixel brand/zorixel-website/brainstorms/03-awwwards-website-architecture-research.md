## ⚡ 2. Top 8 Awwwards Feature Innovations for Zorixel

### 1. Interactive WebGL Fragment Shader Canvas
- **Visual Feel:** Ambient fluid wave or particle distortion responding to cursor movement on desktop/laptop.
- **Awwwards Touch:** Include a floating "Shader Sandbox Control" pill allowing visitors to adjust Shader Frequency, Distortion Speed, and Glow Intensity in real-time.

### 2. Contextual Magnetic Cursor with Mode Switcher
- **Visual Feel:** Smooth inertia cursor circle that dynamically transforms based on hovered element:
  - Over Showcase Grid: Displays `VIEW DEMO`
  - Over Code Inspector: Displays `COPY TSX`
  - Over Product Cards: Displays `BUY KIT`
  - Over Video Preview: Displays `PLAY`

### 3. Live Interactive Component & Design Token Playground
- **Visual Feel:** Allow visitors to edit Zorixel OKLCH color tokens directly on the website and watch the entire design system recalculate live in front of their eyes.
- **Why It Wins Awards:** Proves your technical frontend mastery instantly by letting users interact with your production design engine.

### 4. Havock & Rosehot Kinetic Scroll Choreography
- **Visual Feel:** Words reveal character-by-character with staggered spring physics (`cubic-bezier(0.16, 1, 0.3, 1)` easing) as the user scrolls down the page.

### 5. High-Friction-Free Lead Magnet Modal
- **Visual Feel:** Email input only (zero sign-up barriers). Submitting triggers a celebration confetti burst and displays an instant S3 download button + Supabase subscriber log.

### 6. Slide-Over Store Drawer with Video Demos & Code Trees
- **Visual Feel:** Clicking any digital product opens a fluid right-to-left slide-over drawer displaying:
  - Video walkthrough loop
  - Included file tree structure
  - Clerk-authenticated purchase button
  - Stripe Checkout integration

### 7. Dual Canvas Theme Engine (Obsidian Midnight <-> Warm Linen Cream)
- **Visual Feel:** Smooth OKLCH variable morph between dark (`#0D0E12`) and light (`#FAF8F5`) modes without layout flash or DOM re-renders.

### 8. Real-Time HUD (Performance & Local Time Indicator)
- **Visual Feel:** Subtle bottom-left fixed badge showing FPS (60 FPS indicator), current viewport target (`1920x1080`), and local time (`IST / UTC`).
