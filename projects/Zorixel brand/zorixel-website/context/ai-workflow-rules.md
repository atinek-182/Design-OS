# AI Workflow Rules: Zorixel Brand Website

## Imperative Agent Rules

1. **Strict Pre-Coding Lock (1 to 2 Weeks):** ABSOLUTELY ZERO code writing, file modifications, or code generation until Atinek Maurya explicitly tells you to start coding by himself. Stay strictly in planning/research mode.
2. **Zero Rush & No Prompting to Move Forward:** Do NOT rush planning. NEVER suggest moving forward to code or ask to start writing code.
3. **Strict Zero-Gradient Ban:** NEVER use gradients (color gradients, radial gradients, mesh gradients, text clip gradients) anywhere throughout the website, components, or docs.
4. **Strict Zero-Glassmorphism Ban:** NEVER use glassmorphism, backdrop blurs (`backdrop-filter: blur()`), semi-transparent glass cards, or glass borders anywhere throughout the website.
5. **Trash Asset Ban (`favicon.svg` & `public/previews/`):** `favicon.svg` and `public/previews/` are discarded as AI-slop. Never use them or reference them.
6. **User Reference Priority:** Strictly await and follow the design reference provided directly by Atinek Maurya.
7. **Single-Spec Boundary:** Focus exclusively on the active research topic or spec.
8. **Zero Speculative Code:** When authorized to code in the future, write only code explicitly required by the active spec.
9. **No Placeholders:** Generate real assets, clear copy, and production SVG markup (non-gradient, non-glass).
10. **Playwright Visual Verification Gate:** Run Playwright 5-viewport screenshot captures to verify layout integrity across viewports before claiming completion when coding resume is authorized.
11. **Mandatory Humanizer Writing Discipline:** Apply `humanizer` (33 AI pattern cleanup rules) to ALL copy, headings, chat replies, messages, emails, and docs. Zero em dashes (`—`/`–`), zero promotional puffery, zero AI filler words (*'delve/tapestry/testament'*), zero sycophancy, zero meta-signposting (*'let's dive in'*), and use sentence case for headings with straight quotes (`"..."`).
