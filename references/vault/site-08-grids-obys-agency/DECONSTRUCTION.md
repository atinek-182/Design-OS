## 🔬 Dot-to-Dot 15 Master Web Decision Categories

### 1. Meta, SEO, & Favicons
- OpenGraph Title: `"Grids"`
- OpenGraph Description: `"The educational project about grids which Obys uses every day with unusual storytelling."`
- Favicons: Multi-resolution PNG icons (`144x144`, `114x114`, `72x72`, `57x57`).
- Viewport Config: `width=device-width, initial-scale=1.0, minimum-scale=1.0, maximum-scale=10.0`.

### 2. Preloader & Entrance System
- Minimalist fade-in entrance with black canvas unveiling.
- Session storage flag prevents repetitive preloading on returning visits.

### 3. Navigation & Header System
- Sticky top navigation with `mix-blend-mode: difference`.
- Dynamic chapter counter indicator (`CHAPTER 01/04`).
- Fullscreen navigation drawer overlay with smooth opacity transition.

### 4. Cursor & Pointer Physics
- Custom circle cursor with difference blend mode.
- Expands from `16px` to `48px` on hoverable grid cards and buttons with elastic spring easing.

### 5. Typography & Text Rendering
- Serif Font: `Georgia` (Used for italicized storytelling quotes and section titles).
- Sans Font: `Nobel` / `Inter` (Used for crisp digital typography and grid specs).
- Monospace Font: `Courier New` (Used for ratio specifications and column metrics).

### 6. OKLCH Color Tokens & Theme Engine
- Background Deep Onyx: `oklch(0.12 0.005 240)` (`#111113`)
- Elevated Surface: `oklch(0.18 0.008 240)` (`#191a1d`)
- Accent Gold: `oklch(0.82 0.15 85)` (`#e6c86e`)
- Editorial Red: `oklch(0.62 0.22 25)` (`#e63946`)

### 7. Hero Section Architecture
- Large italicized serif headline (`"Unusual Storytelling"`).
- Subtitle explaining Obys Agency's daily grid practices.

### 8. Scrollytelling & Parallax Engine
- Scrubbed GSAP animation revealing diagonal construction lines of the Van de Graaff canon.
- Column width expansion as the user scrolls into the digital grid section.

### 9. Interactive UI Widgets & Cards
- Interactive Grid Slider widget: Allows real-time tweaking of column count (2 to 24 columns).
- Canons Cards: Highlighting classical page ratio formulas (2:3:4:6).

### 10. Drag-along-Path SVG Slider
- SVG path interpolation for grid guide adjustment lines.

### 11. Proximity-Based Interactive Map Pins
- Euclidean distance calculation for cursor proximity highlighting on grid columns.

### 12. Audio & Soundscape UI System
- Subtle ambient hover feedback sounds on interactive buttons.

### 13. Modals, CTAs, & Form Mechanics
- Embedded newsletter subscription input with regex validation.

### 14. Footer & Page Transition System
- Smooth section transitions between chapters with persistent chapter indicator update.

### 15. 3D Models, Rive Runtimes & Motion Physics Inventory
- Lenis smooth scrolling engine configuration (`duration: 1.2`, `easing: power4.out`).
- WebGL Fragment Shader (`grid-distortion.glsl`) handling interactive canvas hover distortion.
