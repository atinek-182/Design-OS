# Centralized Global Reference Vault

This directory serves as the **evergreen, compounding design intelligence vault** for the Antigravity Design OS.

## Directory Structure
- `archetypes/`: Pre-compiled AST specifications of award-winning digital experiences (`linear-tech.json`, `stripe-developer.json`, `apple-editorial.json`, `cosmos-brutalist.json`).
- `motion-physics/`: Calibrated GSAP easing beziers, spring physics constants, and Lenis smooth scroll profiles (`easings.json`).
- `shaders/`: Ready-to-inject GLSL shaders, SVG noise filters, and multi-point ambient mesh glows (`library.json`).

## Ingestion & Expansion Loop
Whenever you deconstruct a new live website or motion clip during project builds, the deconstructed parameters are compiled and appended here so that all future projects can immediately leverage the new intelligence.
