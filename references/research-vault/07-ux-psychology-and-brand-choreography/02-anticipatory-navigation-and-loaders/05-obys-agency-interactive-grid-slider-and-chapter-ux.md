# Obys Agency — Interactive Grid Slider & Chapter Counter UX Psychology

Obys Agency engages users by providing direct hands-on control over grid layout parameters.

---

## Interactive Grid Slider Manipulation Mechanics

1. **Real-Time Column Tweaking**: An interactive slider allows users to adjust active column counts from 2 to 24 columns in real time. Seeing live elements realign dynamically proves the adaptability of grid systems.
2. **Tactile Agency Proof**: Allowing users to manipulate layout parameters directly builds confidence in Obys' frontend mastery.

---

## Dynamic Chapter Indicator & Fullscreen Drawer UX

- **Chapter Progression**: Top navigation displays a monospaced chapter indicator (`CHAPTER 01/04`) that updates seamlessly as the user scrolls into new grid topics.
- **Difference Overlay Navigation**: The top header utilizes `mix-blend-mode: difference`, ensuring readability over light or dark background sections.
