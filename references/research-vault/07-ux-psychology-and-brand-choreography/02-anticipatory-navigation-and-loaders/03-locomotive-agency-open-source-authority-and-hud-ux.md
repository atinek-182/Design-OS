# Locomotive Agency — Open-Source Tool Authority & HUD Language UX

Locomotive Agency applies **Open-Source Tool Authority** and **HUD Interface Design** to position the agency for high-ticket global client retainers.

---

## Open-Source Ecosystem Tool Authority Framing

1. **Global Developer Tool Ownership**: Creating and maintaining **Locomotive Scroll** — used by tens of thousands of web developers worldwide — establishes Locomotive as the undisputed master of smooth web scroll physics.
2. **Monochrome Digital Authority**: Monochromatic high-contrast layouts signal digital precision and mature technical craftsmanship.

---

## HUD Language Switcher & Percentage Preloader Curtain UX

- **HUD Language Switcher**: Fixed top navigation bar features a clean English/French toggle (`EN / FR`), demonstrating Montréal bilingual heritage.
- **Percentage Preloader Curtain**: Preloader percentage roll (`0%` -> `100%`) coupled with an SVG curtain wipe establishes anticipation before unveiling the hero showcase.
