# The Shift Tokyo — Tokyo Time Clock Anchor & Electric Coral UX

The Shift Tokyo applies **Live Cultural Time Anchors** and **Electric Coral Micro-Glows** to project global creative authority.

---

## Tokyo Time Clock Header Anchor Psychology

1. **Live Geographic Presence**: Displaying a live Tokyo time clock (`東京 18:42:09 JST`) in the fixed header grounds the website in Tokyo's renowned design culture, instilling instant global prestige.
2. **Japanese Neo-Brutalist Craft**: Juxtaposing pitch dark canvases with clean bilingual typography projects progressive Asian design leadership.

---

## Electric Coral Cursor Expansion & Numeric Navigation UX

- **Electric Coral Cursor Expansion**: The custom cursor dot expands smoothly from `12px` to `64px` with a vibrant coral glow (`#FE4249`) when hovering over interactive cards, rewarding user curiosity.
- **Structured Numeric Menu Drawer**: Fullscreen navigation uses numbered index items (`01 Home`, `02 Project`, `03 Research`, `04 About`), creating orderly wayfinding.
