# /responsive-audit
Audit a design for responsive behavior.
## Steps
1. **Breakpoints** — Review behavior at each breakpoint using `better-layout` skill.
2. **Grid** — Check layout grid compliance using `better-layout` skill.
3. **Typography** — Verify type scaling using `better-typography` skill.
4. **Spacing** — Check spacing consistency using `better-layout` skill.
5. **Hierarchy** — Verify hierarchy holds at all sizes using `better-layout` skill.
6. **Touch targets** — Verify minimum sizes for touch using `better-layout` skill.
7. **Report** — Document findings with recommendations.
## Output
Responsive audit report with findings per breakpoint, compliance status, and remediation recommendations.
Consider following up with `/design-screen` to redesign problem areas.
