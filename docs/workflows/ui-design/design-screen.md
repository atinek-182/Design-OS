# /design-screen
Design a complete screen layout from a description.
## Steps
1. **Structure** — Define layout grid using `better-layout` skill.
2. **Hierarchy** — Establish visual priority using `better-layout` skill.
3. **Typography** — Apply type styles using `better-typography` skill.
4. **Color** — Apply color system using `better-colors` skill.
5. **Spacing** — Apply consistent spacing using `better-layout` skill.
6. **Responsive** — Define behavior across breakpoints using `better-layout` skill.
7. **Dark mode** — Specify dark mode adaptation using `glass-dark-ui` skill.
## Output
Complete screen specification with layout, hierarchy, typography, color, spacing, responsive behavior, and dark mode.
Consider following up with `/responsive-audit` to verify the design.
