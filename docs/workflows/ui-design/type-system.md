# /type-system
Create a complete typography system.
## Steps
1. **Scale** — Build a modular type scale using `better-typography` skill.
2. **Hierarchy** — Define hierarchy levels using `better-layout` skill.
3. **Responsive** — Adapt scale across breakpoints using `better-layout` skill.
4. **Spacing** — Define text spacing relationships using `better-layout` skill.
5. **Grid alignment** — Align to baseline grid using `better-layout` skill.
6. **Document** — Output complete type system with usage rules.
## Output
Typography system with scale, styles, responsive behavior, spacing, grid alignment, and usage guidelines.
Consider following up with `/design-screen` to apply the type system.
